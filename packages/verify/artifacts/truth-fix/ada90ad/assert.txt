## The fact, checked at this head before any edit

- `apps/server/src/provider.ts` constructs the real `KeyedProvider` whenever the factory's choice is
  `keyed`, and `auto` chooses `keyed` when the vault at `~/.freebot/provider.env` holds a key. Only
  the non-keyed branch falls through to the replay transcript.
- `apps/server/src/provider.test.ts:12` states the same thing as a test name: "auto takes the vault's
  keyed path when the vault holds a key".
- Gate G1 is open. `apps/server/src/cli/doctor.ts`'s provider key check passes whenever the vault
  holds a key file.
- `apps/server/src/index.ts:47-52` states `replay` on purpose, because it is the entrypoint the
  evidence drivers boot. `packages/verify/scripts/launch.ts:20` says a driver pins the replay provider
  so a recorded turn is what its assertions hold. Both are true statements about a driver's choice.
  "Gate G1 parks the keyed provider" is a false statement about the system, and it is what this unit
  removes wherever it stands in the present tense.
