FreeBot

Local agent workspace

Bots that do the work, on a computer that stays yours.

FreeBot ships no subscription. You bring a model — OpenAI-compatible, local, or hosted — and it gets its own sandbox, a durable workspace, and an approval gate before anything runs.

Connect a provider Run in replay mode — see it work without a key

Both open the app on this computer. Replay is chosen at launch: bun run up --replay forces it even when the vault holds a key, and in auto mode a launch with no key replays the committed transcript instead of calling a model. The connect flow runs a real tool call before it saves a connection.

What runs today

This is a working local install, and some of it is not built yet.

Every line below is true of this repository at the commit that served this page. Nothing here waits for a hosted service, and nothing here needs an account.

01

A Bot is a record with its own sandbox and its own durable workspace at /workspace.

02

Every tool call the run can offer parks on an approval card until you press Allow once or Deny. The gate is fail-closed.

03

Each run gets one Docker container from the pinned image freebot-sandbox:u0.6, removed when the run ends.

04

Your model key lives in your own vault at mode 600. This project ships no key and owns no account.
